# Employee Management System

A simple and user-friendly **Employee Management System** built using **Python Flask, SQLite, HTML, CSS, and JavaScript**.

The application allows users to register and log in securely, manage employee records, search employees, and perform basic employee management operations.

## 🚀 Features

- User Registration
- User Login and Logout
- Password Hashing
- Login Authentication
- Add Employees
- View Employee Records
- Edit Employee Details
- Delete Employees
- Search Employees
- Employee Salary Management
- Joining Date Management
- Dark/Light Theme
- Theme Preference Stored in Browser
- SQLite Database
- Protected Employee Management Pages

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **SQLite**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Werkzeug**
- **Gunicorn**
